# Asset sources

Every graphic in this README is either generated in-repo by the scripts under
`scripts/`, or assembled from the owner's own public pages. Nothing is fetched
from a third-party badge or stats service at render time.

## Generated here

| Asset | Generated by |
|:---|:---|
| `hero-banner*.svg` | `scripts/make_brand_assets.py` |
| `typing-line*.svg` | `scripts/make_brand_assets.py` |
| `footer*.svg` | `scripts/make_brand_assets.py` |
| `divider.svg` | `scripts/make_brand_assets.py` |
| `terminal-portrait.svg` | `scripts/make_terminal_portrait.py` (from `avatar.png`) |
| `telemetry*.svg`, `activity-graph*.svg`, `language-spectrum*.svg`, `contribution-matrix*.svg` | `scripts/make_telemetry.py` (GitHub GraphQL API) |

The `-light` suffix marks the variant served when the visitor prefers a light
colour scheme; `assets/telemetry-data.json` caches the last fetched numbers.

The dot portrait is derived from the profile avatar, which belongs to its owner.
The contribution panels are derived from public GitHub contribution data.

## Project previews

Project previews were assembled from real public page screenshots, captured
without logging in or writing site data:

- M3T Portfolio: https://m3t-z.vercel.app/
- PCVERSE: https://pcverse-lac.vercel.app/
- MOTRYX: https://motryx-delta.vercel.app/ar
- TAFRA: https://tafrawear.vercel.app/
- Marab: https://car-showcase-weld.vercel.app/
- NAWA Studio: https://nawa-studio-dun.vercel.app/

The GIFs are looping page previews assembled from still captures, not screen
recordings of complete interactive workflows. Static fallback images support
reduced-motion preferences. This file does not change licensing terms of the
owner's repositories.
