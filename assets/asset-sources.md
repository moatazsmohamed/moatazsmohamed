# Asset sources

The cosmic banner was created for Moataz Mohamed's profile. The animated version is a camera-motion edit of that existing banner.

Project previews were assembled from real public page screenshots, captured without logging in or writing site data:

- M3T Portfolio: https://m3t-z.vercel.app/
- PCVERSE: https://pcverse-lac.vercel.app/
- MOTRYX: https://motryx-delta.vercel.app/ar
- TAFRA: https://tafrawear.vercel.app/
- Marab: https://car-showcase-weld.vercel.app/
- NAWA Studio: https://nawa-studio-dun.vercel.app/

Technology icons: Skill Icons, https://skillicons.dev/ and https://github.com/tandpfun/skill-icons. Brand marks belong to their respective owners.

The GIFs are looping page previews assembled from still captures, not screen recordings of complete interactive workflows. Static fallback images support reduced-motion preferences. This file does not change licensing terms of the owner's repositories.
